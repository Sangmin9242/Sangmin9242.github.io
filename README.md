## Publish with GitHub Pages

This repository is currently private. GitHub Pages is not enabled. Publishing the website publicly requires a separate decision.

To use a project repository instead, enable Pages for that repository and open its project URL. Relative asset paths work in either setup.

## Update the CV

Edit the publication entries and profile text in `index.html`. Each DOI in the publication list links to its publication page. Review all public claims and institution wording before publishing.

The supplied PDF contains personal details. The page intentionally omits the home address, phone number, and birth date. Korean paper, patent, and project titles have been translated into English; review wording before public release. Duplicated conference papers appear only once. Empty career and certification fields and red editorial reminders in the source are not achievements and are omitted.
