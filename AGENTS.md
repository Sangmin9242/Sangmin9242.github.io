# Interactive homepage

Edit the readable root JavaScript and CSS sources. The published entry is `assets/build/site-start.js`; regenerate it with `npm run build` after changes to JavaScript, then commit the generated `assets/build` files along with the sources. Keep previous hashed chunks available for visitors who cached an earlier entry.

Keep model geometry, material maps, pixel ratio and shadow resolution intact when optimizing. Only explicitly marked stationary mesh leaves may be batched; collision poles and independently animated or interactive objects must retain their identity. Never modify NAS or desktop originals when producing compressed assets.
